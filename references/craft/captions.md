# Captions

- Transcribe with `scripts/transcribe.py` (mlx-whisper large-v3-turbo, word timestamps, `--lang ru` — the user speaks Russian; another language only when the material is in it). It assembles the exact timeline audio first — segments at their timeline positions (gaps silent), CapCut speed changes time-stretched, muted segments silent, CapCut voiceovers mixed in — so times are already timeline times and nothing muted gets a caption.
- Group with `scripts/make_captions.py` → `reel/public/captions/timeline.json` (Remotion `Caption[]` with `pageBreakAfter`). Defaults from `numbers.md`: pages ≤ 8 words, ≤ 3.4 s and ≤ 54 characters (two lines at 50 px; a longer page would wrap to a third line and climb into the card band), never breaking after a function word; 1–2-word pages are glued to the next phrase; tokens in silent ranges and after the speech end are dropped (Whisper hallucinates «Продолжение следует…» on silence); swears are masked with asterisks (`--no-mask` when the intake says leave them).
- Display with the template `Captions.tsx`: Montserrat 700, 50 px, white with `shadows.caption`, centred, bottom at ≈ 1520. A phrase followed within 1.4 s by the next one soft-swaps (4-frame overlap, opacities sum to 1, 6 px rise) — never fade to zero between two phrases, that reads as a blinking line; only a real pause gets the 9-frame fade, with the phrase held 0.65 s after its last word. The last page fades inside the reel instead of being cut off; a page that still exceeds two lines shrinks its font (min 40 px). No per-word colour, no bounce.
- Print the page list and read it: fix hallucinated or dropped words in `work/caption_patches.json` (`drop` tokens, `drop_at` with a time, `replace` by token text, `replace_at` with a time) — `make_captions.py` and `tl_words.py` apply it on every run, so fixes survive a re-cut; never edit the generated JSON. Typical issues: brand names (`assets/brands.json` holds the canonical spellings), names misheard in narration, a number spoken one way and written another — write what was said («полтора миллиона», «1,5 млн» only if the user writes it so). Fillers like «короче» stay: it is the author's voice.
- `drop` / `drop_at` match RAW whisper tokens, before gluing: an interjection like «Уи-хи» arrives as « Уи» + «-хи.», so a drop of «Уи-хи.» never fires — drop both pieces with `drop_at` (birthday reel, 2026-10-22).
- Word timestamps double as the sync source for every graphic: `scripts/tl_words.py` writes `work/tl_words.txt` (frame + word, brands and patches applied, silent ranges skipped); `work/gen_reel.py` looks words up through `reelgen` (`craft/scenes.md`).
- Profanity: the one matcher is `scripts/swear.py` (shared by `make_captions.py`, `cut_from_transcript.py`, `bleeps_from_timeline.py`; it knows innocent look-alikes such as «себестоимость», «подъезд»); extend it there when a word slips through or a harmless word is caught, and run its self-test (`python3 -I $S/swear.py`).
