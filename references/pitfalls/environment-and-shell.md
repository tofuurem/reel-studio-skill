# Environment and shell

Setup, zsh traps, background jobs, disk, model weights. Each item cost real time on a production (2026-10-09 … 2026-10-21); read the file of the area you are about to touch.

- **zsh modifiers inside strings**: `$H:flags` is read as the `:f` modifier (ffmpeg saw `1920ags`), `"$n:layout"` as `:l` (lower-case, eats the `l`). Write `${W}:${H}`, `${n}:layout`.
- System disks run near full (one hit 363 MB free; even the harness could not write tool output). Before proxying check `df -h /`; `make_proxies.py` warns. Safe to reclaim: `uv cache clean` (~3 GB), `npm cache clean --force`, this session's scratchpad, `work/voice/in`, `work/stills`, `work/faces`. Never wipe `~/Library/Caches` wholesale or the user's renders without asking.
- `@remotion/bundler`'s `bundle()` copies the whole `public/` folder into its output dir; with proxies inside that is ~1 GB per call, and crashed runs leave `/var/folders/…/T/remotion-webpack-bundle-*` behind (29 of them = 16 GB on 2026-10-09). `stills.mjs` now bundles into `work/bundle_<pid>` and deletes it, `render.sh` sets `TMPDIR=<project>/work/tmp`; if space vanishes, `rm -rf "$TMPDIR"/remotion-webpack-bundle-* "$TMPDIR"/react-motion-render*`.
- `pgrep -f "a\|b"` is not alternation (ERE) — the background waiter exits immediately and reports "prep exited" while the job is alive. Use `pgrep -f "work/prep.sh"` with one literal pattern.
- **zsh and globs that match nothing** abort the whole command line (`no matches found`), even behind `&&` and inside `set -e` scripts: a `for f in *.jpg` over an empty folder, `*.mp4` in a folder of `.MP4`, or `rm -f dir/*.mp4` silently stopped everything after them (once the re-encode after an `rm` never ran and old proxies were rendered). Every script and chained command with a glob needs `setopt null_glob`, or explicit file names.
- `setup_env.sh` died on its second run: macOS `cp -n` exits 1 when the file exists and `set -e` took the script down before `ENV_OK`; it also only checked that a venv python existed, not that the packages were importable. Now it imports `mlx_whisper`/`Vision`/`df` to decide.
- `create-video` refuses a non-empty `reel/`, and `make_proxies` creates `reel/public/footage` — `scaffold.sh` builds in a temp dir and merges. It used to `rm -rf src` whenever `Clip.tsx` was missing, so a background scaffold could wipe a `Timeline.tsx` that `gen_timeline.py` had just written (audit 2026-10-22); it now only adds template files and keeps generated ones, so `gen_timeline.py` may run before it finishes; tsc and renders wait for `SCAFFOLD_OK`. Remotion and every `@remotion/*` package are pinned (`REMOTION_VERSION`, default 4.0.534): `create-video@latest` once gave one project 4.0.537.
- **Background jobs you `pkill` to patch a script**: restart them explicitly and verify with `pgrep -fl` — a restart typed after a failed glob never started, and the 2K proxies were missing an hour later.
- **Handy's Parakeet GGUF → parakeet-mlx.** Handy (`com.pais.handy`) keeps `parakeet-tdt-0.6b-v3-Q8_0.gguf` in the HF cache (custom `parakeet` arch, `stt.*` keys) and ships no CLI. The tensors map 1:1 to parakeet-mlx (697, same vocab); only names and conv layouts differ (PyTorch OIK/OIHW → MLX channels-last). `gguf2mlx.py` converts in seconds; the fp32 mlx-community download is 2.5 GB and crawled at 0.7 MB/s here.
- **A `coverage/` folder in the cwd breaks mlx_whisper** (numba imports it as a namespace package → `module 'coverage' has no attribute 'types'`). Happens when Python runs from a JS repo with jest coverage output; always `cd <project>` and use `-I` (setup_env's import checks now do).
- **`setup_env.sh` could not finish on a machine without Handy** (audit 2026-10-22): under `null_glob`, `ls <glob with no match>` runs as plain `ls` and listed the current folder, so `GGUF` became `NOTES.md`, the conversion crashed and `set -e` stopped the script before the LUT copy and `ENV_OK`. Globs are assigned to arrays now (`g=(…(N))`); test new globs in scripts the same way.
- **`voice_isolate.sh` failed on a re-run** when every input was already done: `rm -f …/in/*.wav` matched nothing and zsh aborted (`no matches found`, no `VOICE_DONE`).
- **Renders depended on the network**: fonts came from Google Fonts and two SFX from remotion.media at render time — offline, the render waited until it timed out. Fonts are local files now: `setup_env.sh` downloads them once into `~/.cache/reel-studio/fonts`, `scaffold.sh` (and `setup_env.sh`, when `reel/` already exists) copies them into `reel/public/fonts`, `cover.sh` into the covers' public folder; all SFX are synthesised by `make_sfx.sh`.
- After editing the skill run `python3 -I $S/selfcheck.py`: numbers generated, scripts compile and answer `--help`, every flag the docs use exists, the template passes the lint.
- **The project folder was hardcoded** (2026-11-06): the user started the session in the folder on an external drive that held the camera file and wanted THAT folder to be the project. `projects_dir.py` now suggests the folder Claude Code is open in (SKILL.md §1.1), the user confirms it, and `new_project.sh` never moves the user's files.
- **exFAT project volume** (same reel; `Photo&Video`, 1 MB clusters): `node_modules` (≈ 24 k files) would take ≈ 24 GB there and crawl. A pre-made `reel/node_modules` symlink broke scaffold (`cp: …/node_modules: Not a directory` — create-video had installed into the temp dir) and `npm i --save-exact` then silently replaced the link with a real folder on exFAT. `scaffold.sh` now detects a volume other than `$HOME`'s, moves the blank project's install to `~/.cache/reel-studio/npmroot/<name>-<hash>/node_modules`, links it, and runs npm there on a copy of `package*.json`. Never run `npm` inside `reel/` on such a volume.
- **AppleDouble `._*` files in `reel/src`** (same reel): macOS writes `._Reel.tsx` next to every file it creates on exFAT (the `com.apple.provenance` xattr), even for files written by Python or ffmpeg. `reelgen` read them as TypeScript → UnicodeDecodeError, `tsc` compiled them. reelgen, lint_reel and actiongen skip dot files now; scaffold adds `**/._*` to tsconfig's `exclude`.
- **`rm -rf` on a folder at the top level of a mounted drive is refused** by Claude Code's safety check (even a test folder you just made there): create test projects deeper (`/Volumes/<drive>/<folder>/…`) or ask the user to delete it.
- **`python3` without `-I` fails with «Interrupted system call»** (2026-11-08) when the working folder is on the iCloud-synced Desktop: the interpreter puts the folder on `sys.path` and its `stat` is interrupted by the file provider. Always `python3 -I` (the skill's rule anyway) or `cd` elsewhere for ad-hoc snippets.
- **yt-dlp: «SSL: UNEXPECTED_EOF» while curl reaches the same site** (2026-11-08): the connection to the video site is filtered (YouTube throttling); a VPN fixes it, retries do not. `fetch.py` then tells the user to download the file themselves.
