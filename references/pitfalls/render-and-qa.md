# Render and QA

Rendering environment, single-frame dropouts, temp bundles, QA habits. Each item cost real time on a production (2026-10-09 … 2026-10-21); read the file of the area you are about to touch.

- `--scale`-free 2K: render the `Reel2K` composition (CSS scale 4/3) with `REMOTION_FOOTAGE_DIR=footage2k`.
- **Renders suddenly time out with "Waiting for root component to load"** and even `chrome-headless-shell --dump-dom data:…` hangs at 0 % CPU with `CVDisplayLinkCreateWithCGDisplay failed. CVReturn: -6670` in stderr → macOS has a virtual display (check `system_profiler SPDisplaysDataType`; a "FlipAction16" 2048x1280 display appears with Screen Sharing in high-performance mode / ScreenSharingSubscriber, also DisplayLink or Sidecar). The bundled headless shell never produces a frame; the installed Google Chrome works. `remotion.config.ts` and `stills.mjs` in the template already prefer `/Applications/Google Chrome.app`. Kill stuck shells with `pkill -9 -f chrome-headless-shell`.
- Keep the Mac awake during long renders (`caffeinate -dis` or the host keep-awake tool); a sleeping display also stalls Chrome.
- Render contact sheets at: cold open, each chapter tag, each card mid-animation, every b-roll in/out point, outro. Compare against `face_zones.json` before the full render.
- A 2.5-min 2K render ≈ 5 min on M-series with one tab (CONC=1; four tabs are not faster and produce dropouts). Run in the background and verify loudness, the glitch scan and a few frames of the final file.
- QA sheets: `qa_sheet.sh` (16-tile pages); `contact_sheet.sh` takes the project path as given (relative works since 2026-10-22).
- **Cards "blink" (text vanishes for one frame, panel stays)**: `backdrop-filter: blur()` on a card promotes it to its own compositor layer and Chrome occasionally screenshots the frame before the text layer is rasterised (random single frames, more under 4× concurrency). Diagnose with `scripts/glitch_scan.py <file>` (frame-to-frame diff in three bands; render.sh runs it). Fix: no backdrop-filter anywhere in the composition; use a solid rgba panel. Captions with text-shadow are fine.
- **Half-drawn panels on single frames even without backdrop-filter** (a card's panel cut off mid-way, frame 882 of FOMO v3b): GPU tile rasterisation with `gl: "angle"` on the Mac that has a virtual display (Screen Sharing) is not always finished when Remotion screenshots. Do NOT switch to `swiftshader`: on this Mac it drops stamps and cards on every other frame (period-2 flicker, 80+ bad frames). Keep `angle`, render with `CONC=1 render.sh …` (single tab, no GPU contention) and always run `glitch_scan.py` on the final file over three bands (cards 1000–1700, face 200–1000, captions 1700–2400 in 2K px) before delivering.
- **Render died mid-way with 404 on `public/footage2k/<clip>.mp4`** (lofiroom ep1, frame ≈2300/4343): the proxy was on disk, but Remotion's temporary webpack bundle under `/var/folders/…/T/remotion-webpack-bundle-*` had disappeared while rendering. A plain re-run of `render.sh` succeeded; `render.sh` now keeps the bundle in `<project>/work/tmp` (it sets `TMPDIR` itself), so nothing else can sweep it away.
- **Stills or a render while `make_proxies` wrote into `reel/public`** died: the bundler copies the folder and exits on a `.tmp.mp4` that disappears (the only output was `Node.js v26…`). Proxies are written in `work/tmp` and moved in complete now; still wait for `PROXIES_DONE` before a render — a proxy that is not there yet is a 404 mid-render.
- **`mix-blend-mode` on an overlay is as risky as `backdrop-filter`** (birthday reel v5, 2026-10-22): a `screen`-blended light wash over footage produced one single-frame dropout in the water band (`glitch_scan` BAD 1 at 146.87 s). Blend modes promote the element to its own compositor layer. Fake the light with plain opacity gradients instead. The audit the same day found the template's own `Flash` still had `mixBlendMode: "screen"` — on every chapter of every reel; it is a plain radial gradient now, and `lint_reel.py` fails on any blend mode or backdrop-filter.
- **`GLITCH_SCAN CLEAN` on a broken file** (audit 2026-10-22): a missing or truncated render decoded 0 frames and passed; `render.sh` printed `RENDER_DONE` even when the final mux failed. `glitch_scan.py` now compares the decoded count with the expected one (exit 2 = broken), `render.sh` fails on it, checks the frame count of the final file and refuses to start when `doctor.py --pre-render` finds errors (`FORCE=1` overrides).
- **Proxies that silently stayed stale** (audit 2026-10-22): an interrupted encode left a half file that later runs reported as done; the reuse check looked only at the window start, so a longer window, a new voice dir or a re-cut with only the 1080 pass re-run kept old files — Reel2K was a second off while Studio looked right. Every proxy folder has a `.manifest.json` (source, window, voice, LUT, crf, speed) and any mismatch re-encodes; `doctor.py` compares both folders with the cut list.
- **Landscape projects** (Halloween vlog, 2026-11-01): the template is 9:16; a 16:9 video needs `theme.ts` W/H swapped (Reel2K stays ×4/3 → 2560×1440), `numbers.ts` punchCenterY near 430, the cut list's canvas set to 1920×1080 after `cut_from_transcript.py` (it writes 1080×1920), and its own overlay components. `qa_sheet.sh` now tiles 16:9 stills as 640×360; `doctor.py` reads `work/lut_map.json` so an explicit "none" is not a grey-clip error.
- **DeepFilterNet leaves digital silence on picture beats** (a costume dance, a bike ride): a vlog without music then has dead holes. Mix the camera's own sound (L+R downmix, ~8 dB under speech) under picture beats; a beat whose source audio has a dropout (wireless mic reconnect: no audio packets at all, ffmpeg returns 0 bytes) cannot be saved — Parakeet still "heard" a line there.
- **«2K only» intake had no 1080 proxies, and four tools assumed them** (reel-studio skill reel, 2026-11-05): `transcribe.py` read the timeline audio from the empty `footage/` folder and Whisper filled 4 minutes of silence with «Продолжение следует…»; `qa_sheet.sh` stills 404-ed; `face_zones.py` / `night_lift.py` measured nothing. `common.proxy_file()` now falls back to `footage2k/`, `qa_sheet.sh` sets `REMOTION_FOOTAGE_DIR=footage2k` when `footage/` is empty, and `doctor.py` no longer counts the music bed's default path in `Sfx.tsx` as a missing asset when the reel has no `MusicBed` (music: none). Run doctor with `--comp Reel2K` on such projects (render.sh does).
- **16:9 on a speaker who is not centred** (same reel): the template Captions used the 9:16 bottom pad (400 px → text in the middle of a 1080-high frame) — `Captions.tsx` now switches to a 1240 px column with the text bottom at ≈ 960 when W > H. A static wide shot put the speaker at x 0.10–0.52 after the punch: measure it per segment with Apple Vision on the proxies (`people_zones.vision()` on one frame at 20 % and 80 % of each clip) before placing panels; all panels went to the free right column, ≥ 32 px body text (28 px read as tiny on a phone in a horizontal video). `scaffold.sh` sets W/H only from `work/intake.json` — write the intake before the scaffold, or re-run it.
