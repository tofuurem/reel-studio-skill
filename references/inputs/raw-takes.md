# Input: raw camera takes (no edit)

Use for one-shot monologues, several takes of the same talk, over-the-shoulder footage, acting/mocap takes — anything from the camera that nobody has cut yet. Claude proposes the cut; the user approves it.

1. **Look first.** `python3 -I $S/inventory.py <project> <clips or folders>` → table (duration, orientation, sound level, notes) + `camera.jpg` with one graded frame per clip. Classify each clip: talking head, b-roll, acting, unusable.
2. **Map the speech.** `work/gigvenv/bin/python -I $S/transcribe_gigaam.py <clips with sound>` → `work/pk/c<id>.json` (`[{start, end, text, words:[{w, s, e}]}]` in source seconds; GigaAM v3 + Silero VAD: ≈ 20× realtime, punctuation, sentences split at . ? !, no text invented on wind / engine; it re-runs itself under `mem_guard.py`, ≈ 1.5 GB; the model downloads once, ≈ 1 GB — say so). GigaAM is Russian only: for another language the first pass is `transcribe.py --sources --lang <code> <clips>` (Whisper, → `work/new/c<id>.json`, already in the step-4 format; ≈ 1.6 GB model on first use; never on silent clips — Whisper invents text there). Read it like an editor: who says what where, which takes repeat a point, what the ending is. Word ENDS are ±0.1–0.26 s — good for a plan, not for a cut point (step 4).
3. **What can be made of it.** Count the usable speech: up to ≈ 2:30 is one reel; more is a series (`inputs/series.md`) or a reel plus shorts. Offer the options with lengths, then **propose the structure** to the user: chapters, the source ranges (clip + seconds) for each, the ending, what is left out. For a series, write it into `PLAN.md` (`inputs/series.md`). Wait for the OK.
4. **Exact words and boundaries.** `$S/voice_isolate.sh <project> <takes…>`, then `work/gigvenv/bin/python -I $S/transcribe.py --sources <takes…>` → `work/new/c<id>.json` (or `pk2words.py work/pk/c<id>.json` for a plan-only pass). Measure real pauses with `python3 -I $S/pauses.py work/voice/out/c<id>_DeepFilterNet3.wav <start> <dur> [thr_db] [min_s]`. An exact range is cut where you put it: place both ends inside the pause, with about the same margin cut_from_transcript.py keeps around word-snapped ranges (plan `lead` / `tail`, default 0.12 s before the first word and 0.25 s after the last).
5. **The plan.** `work/plan.json`:
   ```json
   {"files": {"0171": "/abs/DJI_…_0171_D.MP4", "0137": "/abs/DJI_…_0137_D.MP4"}, "words": {"0171": "work/new/c0171.json"},
    "voice": {"0171": "work/voice/out/c0171_DeepFilterNet3.wav"}, "exact": true,
    "plan": [["0171", 156.10, 164.50, "cold open", {"audioFadeIn": 4}],
             ["0137", 28.0, 34.0, "silent wide shot tail", {"transition": "whip", "mute": true, "punch": 1.0}]],
    "broll": ["work/broll/DJI_…_0141b_D.MP4"]}
   ```
   Options per range: `exact`, `transition` (a seam kind from `craft/transitions.md` §1; most cuts stay the default dissolve — §0), `audioFadeIn` (frames, when a cut lands inside a word), `mute` (a picture-only segment; always exact, needs no transcript), `punch` (framing scale; `gen_timeline.py --punch 1.2` for small figures in wide shots), `drift` (the slow push-in of this range, default `punchDrift`; `0` for a picture with a baked frame or window — two ranges of it would jump in size at the dissolve), `cropX` (the 9:16 crop centre of a landscape clip, 0–1 of its width, or `[from, to]` for a pan — overrides `people_zones.py`), `amb` (a picture beat with the camera's own sound under it, via dialogue.py), `raw` (camera sound instead of the cleaned voice), `speed` (≥ 1 for picture beats), `snap: false` / `gaps: true` (no sentence growth / no pause split for this range). Plan-level `lead`, `tail`, `snap` (default on), `splitPauses`, `splitWindows`, `canvas` — see `cut_from_transcript.py --help`. Only the takes the plan uses become sources (unused takes are not encoded).
6. `python3 -I $S/cut_from_transcript.py work/plan.json [--lut "$LUT"]` → `work/cutlist.json` + `work/bleeps.json` (swears snapped to the voice); an empty, backwards or sub-frame range stops it with `PLAN ERRORS` and nothing is written. Continue with the core pipeline: the takes are isolated already (step 4 here), so start at people → crop (step 2); levels between takes and mics are `dialogue.py`'s (step 6).

Footage specifics:
- **Long takes**: `make_proxies.py --trim-to-cutlist 2` encodes only the used window (± 2 s). B-roll from the unused part of a take that is NOT in the cut list: `--extra "<take>@<start>-<end>"` encodes just that window (muted; `BRoll` trims by `proxy_offsets.json`). Never pass a take that IS in the cut list to `--extra`: its proxy is then encoded for the extra window only and the cut's own segments no longer fit — make a snippet in `work/broll/` instead (a stream copy, as `new_project.sh` creates; keeping the `DJI_` prefix keeps the LUT).
- **Horizontal camera clips** (`DJI_*` 3840×2160) are cropped to 9:16 (with the LUT) where the people are: run `people_zones.py --sheet` first and look at the sheet. Without zones for every landscape segment `make_proxies.py` stops before encoding; `--centre-crop` accepts a centre crop on purpose. Wrong person or position → `cropX` on that range in plan.json, re-run the cut, people_zones.py and the proxies. DJI b-roll passed with `--extra` is centre-cropped (zones cover cut-list segments only); for another position grade and crop it by hand into `work/broll/<name>.mov` (`lut3d=file='$LUT',crop=1215:2160:<x>:0,scale=1440:2560`) without the `DJI_` prefix.
- **A swear GigaAM mishears** is neither bleeped nor masked. Fix the word in the source `work/new/c<id>.json` (keep a `.bak`) before running cut_from_transcript.py, so it lands in `work/bleeps.json`, and mask it in the captions: a `replace_at` with the right word in `work/caption_patches.json` (make_captions.py masks it after patching; `craft/captions.md`).
- **Acting / mocap takes** shown next to their result: measure the moment of the action in every source (frames every 0.5 s) and set each window's `trimBefore` from it (`pitfalls/cut-and-timeline.md`, synced windows). Clip ids must be unique in a project: when two clips share a DJI counter, `ingest.py --camera link` gives the second link a `b` suffix.
- **When asked to shorten**: cut whole clauses at real pauses and list what was cut with timecodes in `NOTES.md`.
