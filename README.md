# reel-studio

Скилл для [Claude Code](https://claude.com/claude-code): монтирует рилсы и влоги в [Remotion](https://www.remotion.dev) из черновика CapCut, сырых дублей, закадра со скринкастами или картинок. Чистит голос, делает субтитры и графику, рендерит в 2K. Умеет экшн-рилсы под бит трека и длинные влоги с двух камер.

## Что умеет

- **Любой исходник.** Черновик CapCut переносит один в один. Из сырых дублей сам предлагает план монтажа по расшифровке и ждёт твоего «ок». Ещё умеет закадр поверх скринкастов, ролик только из картинок и серию выпусков из общего пула материала.
- **Звук.** Чистит голос через DeepFilterNet и выравнивает громкость между дублями и микрофонами. Сводит две петлички, если на событии было две камеры. Подкладывает тихий лоу-фай фон и сводит итог в −16 LUFS. Резонансы, «гудение» и плавающую громкость голоса правит по запросу, после сравнения вариантов на слух.
- **Субтитры.** Русскую речь расшифровывает GigaAM v3, остальные языки — Whisper. Субтитры спокойные, с запиканным матом.
- **Монтаж и графика.** Кадрирует 9:16 по людям и ставит титр за человеком. Есть моушн-сцены, главы, обложки и комиксные надписи.
- **Переходы с бюджетом.** Склейки по совпадению кадра и по силуэту, J/L-звук между сценами, акценты под бит. Скилл сам следит, чтобы эффектов не было слишком много подряд.
- **Звуковые эффекты.** Синтезирует свои или, с earshot, берёт из его библиотеки. Может найти настоящий звук на [Openverse](https://openverse.org) и проверить «на слух», что каждый эффект слышен на своём кадре.
- **Цензурная версия.** Вторая версия того же монтажа: запиканы мат и разговоры про траву, в субтитрах маски, косяки и вывески в кадре размыты с трекингом.
- **Проверки.** Перед рендером проверяет проект, после — громкость, выпавшие кадры, каждую склейку и «замёрзшие» куски. Тяжёлые шаги на macOS идут под защитой памяти, чтобы модель не повесила машину. Если неясно, какой вариант лучше, собирает короткий A/B, а не рендерит всё целиком.

## Установка

Вставь в Claude Code:

```text
Установи скилл reel-studio: склонируй https://github.com/tofuurem/reel-studio-skill в ~/.claude/skills/reel-studio, сначала спроси меня, ставить ли генерацию обложек через Codex CLI и звуковой модуль earshot (≈ 1,6 ГБ: живые звуковые эффекты вместо синтезированных и проверка звука в готовом ролике), затем запусти python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install (с --with covers и/или --with sound — что я выберу) и доведи до DEPS_OK. То, что требует пароля, дай мне выполнить самому.
```

Или вручную (на чистом Маке сначала `xcode-select --install`, чтобы появились `git` и `python3`):

```bash
git clone https://github.com/tofuurem/reel-studio-skill ~/.claude/skills/reel-studio
python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install
```

Проект создаётся в папке, где открыт Claude Code. Перед созданием Claude спросит, туда ли. Постоянную папку для проектов можно задать в `REEL_STUDIO_PROJECTS`.

`deps.py` без флагов только проверяет и пишет, чего не хватает. С `--install` ставит ffmpeg, node, uv и Python-окружения, при этом сам определяет систему. Флаг `--with covers` добавляет Codex CLI для сгенерированных обложек, для него нужен вход в ChatGPT через `codex login`. Флаг `--with sound` добавляет [earshot](https://github.com/Leonxlnx/earshot) (≈ 1,6 ГБ, работает на процессоре). С ним звуковые эффекты берутся из его библиотеки, а не синтезируются, найденные на Openverse звуки ранжируются по звучанию, а готовый ролик проверяется «на слух». Без earshot поиск на Openverse тоже работает, только без ранжирования.

Модели скачиваются при первом использовании:

| модель | зачем | размер |
|---|---|---|
| GigaAM v3 + Silero VAD | расшифровка русской речи | ≈ 1 ГБ |
| Whisper large-v3-turbo | расшифровка речи на других языках | ≈ 1,6 ГБ |
| DeepFilterNet 3 | чистка голоса | ≈ 8 МБ |
| Qwen3-VL-8B, 4 бита (необязательно) | описание кадров, только Apple Silicon, Claude спросит перед загрузкой | ≈ 5,4 ГБ |

## Обновление

Вставь в Claude Code или Codex:

```text
Обнови скилл reel-studio: найди, куда он установлен (обычно ~/.claude/skills/reel-studio), сделай там git pull и коротко расскажи, что изменилось. Если в папке есть мои локальные правки или pull конфликтует, ничего не затирай и сначала спроси меня. Затем запусти python3 -I <папка скилла>/scripts/deps.py: если в новой версии появились необязательные части, которых у меня нет (например --with sound), спроси, ставить ли их; потом deps.py --install с выбранными --with и доведи до DEPS_OK — новая версия может требовать новых инструментов. То, что требует пароля, дай мне выполнить самому.
```

Или вручную: `git -C ~/.claude/skills/reel-studio pull`, затем `python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install`.

## Платформы

| система | что работает |
|---|---|
| macOS, Apple Silicon | всё |
| macOS, Intel | всё, кроме описания кадров; Whisper без MLX работает медленнее |
| Linux, WSL2 | не работает то, что держится на Apple Vision: кадрирование по людям, титр за человеком, вырезанные обложки. Нет описания кадров и защиты памяти |
| Windows | только через WSL2 |

LUT камеры в репозиторий не входит, подробности в [assets/luts](assets/luts/README.md).

## Использование

Попроси Claude Code своими словами: «собери рилс из этих дублей», «вот черновик в капкате», «экшн-рилс под трек», «сделай цензурную версию». Основная инструкция скилла в [SKILL.md](SKILL.md), подробности в [references](references).
