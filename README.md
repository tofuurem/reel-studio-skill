# reel-studio

Скилл для [Claude Code](https://claude.com/claude-code): монтирует рилсы, шортсы и влоги в [Remotion](https://www.remotion.dev) и рендерит их в 2K.

## Установка

Вставь в Claude Code:

```text
Установи скилл reel-studio: склонируй https://github.com/tofuurem/reel-studio-skill в ~/.claude/skills/reel-studio, сначала спроси меня, ставить ли генерацию обложек через Codex CLI и звуковой модуль earshot (≈ 1,6 ГБ: живые звуковые эффекты вместо синтезированных и проверка звука в готовом ролике), затем запусти python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install (с --with covers и/или --with sound — что я выберу) и доведи до DEPS_OK. То, что требует пароля, дай мне выполнить самому.
```

Или вручную (на чистом Маке сначала `xcode-select --install`):

```bash
git clone https://github.com/tofuurem/reel-studio-skill ~/.claude/skills/reel-studio
python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install
```

`deps.py` сам определяет систему и ставит ffmpeg, node, uv и Python-окружения. Без флагов он только проверяет, чего не хватает. Есть два необязательных флага:

- `--with covers` ставит Codex CLI для сгенерированных обложек, нужен вход через `codex login`;
- `--with sound` ставит [earshot](https://github.com/Leonxlnx/earshot).

Всё работает на macOS с Apple Silicon. На Intel-Маке нет описания кадров. На Linux и WSL2 нет ещё и того, что держится на Apple Vision: кадрирования по людям, титра за человеком и вырезанных обложек. Windows поддерживается только через WSL2.

## Обновление

Вставь в Claude Code или Codex:

```text
Обнови скилл reel-studio: найди, куда он установлен (обычно ~/.claude/skills/reel-studio), сделай там git pull и коротко расскажи, что изменилось. Если в папке есть мои локальные правки или pull конфликтует, ничего не затирай и сначала спроси меня. Затем запусти python3 -I <папка скилла>/scripts/deps.py: если в новой версии появились необязательные части, которых у меня нет (например --with sound), спроси, ставить ли их; потом deps.py --install с выбранными --with и доведи до DEPS_OK — новая версия может требовать новых инструментов. То, что требует пароля, дай мне выполнить самому.
```

Или вручную: `git -C ~/.claude/skills/reel-studio pull`, затем `python3 -I ~/.claude/skills/reel-studio/scripts/deps.py --install`.

## Использование

Попроси Claude Code своими словами, например: «собери рилс из этих дублей», «вот черновик в капкате», «экшн-рилс под трек» или «сделай цензурную версию». Проект создаётся в папке, где открыт Claude Code, и Claude перед этим спросит, туда ли. Постоянную папку для проектов можно задать в `REEL_STUDIO_PROJECTS`.

**Что умеет**

- **Исходники.** Черновик CapCut переносит один в один. Ещё работает с сырыми дублями, закадром со скринкастами, картинками, серией выпусков, влогом с двух камер и экшн-рилсом под бит трека. Для сырых дублей сам предлагает план монтажа и ждёт твоего «ок».
- **Голос.** Чистит, выравнивает громкость между дублями и сводит в −16 LUFS.
- **Субтитры.** Ставит спокойные субтитры с запиканным матом.
- **Монтаж и графика.** Кадрирует по людям, ставит титр за человеком, добавляет моушн-сцены, главы и обложки. Делает переходы и следит, чтобы эффектов не было слишком много подряд.
- **Звук.** Подкладывает тихий фоновый трек. Звуковые эффекты синтезирует сам, берёт из earshot или находит настоящие записи на [Openverse](https://openverse.org).
- **Цензурная версия.** Делает вторую версию того же монтажа: мат запикан, лишнее в кадре размыто.
- **Проверки.** До и после рендера проверяет громкость, выпавшие кадры и склейки. Если неясно, какой вариант лучше, собирает короткий A/B.

**Что скачивает при первом использовании**

| что | зачем | размер |
|---|---|---|
| GigaAM v3 + Silero VAD | расшифровка русской речи | ≈ 1 ГБ |
| Whisper large-v3-turbo | расшифровка речи на других языках | ≈ 1,6 ГБ |
| DeepFilterNet 3 | чистка голоса | ≈ 8 МБ |
| earshot (с `--with sound`) | библиотека эффектов и проверка «на слух» | ≈ 1,6 ГБ |
| Qwen3-VL-8B (необязательно, Claude спросит) | описание кадров, только Apple Silicon | ≈ 5,4 ГБ |

LUT камеры в репозиторий не входит, подробности в [assets/luts](assets/luts/README.md). Полная инструкция скилла лежит в [SKILL.md](SKILL.md).
